# Dialogue script — Tomkin and the Lighthouse Leviathan

Every spoken line, in order, with timecodes. Veo generates these lines in-clip (lip-synced). For re-voicing, record/TTS each line to `audio/dialogue/shot_###.wav` and it will be mixed over the clip.

## Voice sheet

| Character | Voice |
|---|---|
| Tomkin | crisp, rapid-fire, precise male tenor with a clipped British accent; superior, exasperated, always certain he is the only rational being in the room |
| Marvel the Wizard | deep, warm, sonorous elderly male voice with a theatrical storyteller's cadence, slow and serene, narrating himself in the third person |
| Duggie | goofy, warm, slightly gravelly young male voice; in FAST mode a breathless machine-gun stutter of words; in SLOW mode a deep, stretched, slowed-down drawl as if recorded at quarter speed |
| Gary the Fly | no words; only a tiny, self-satisfied buzz |
| Ben Elf | high-pitched, chipper, officious little male voice, delighted by everything, speaking in excited exclamations |
| Princess Holly | soft, sweet, gentle young female voice, kind and nervous, apologising quickly, words tumbling out |
| The Grumpy Glitch-Bots | flat, monotone, bit-crushed robotic voices, speaking in ALL-CAPS bureaucratic announcements, sometimes in unison |
| The Big Glitch-Bot | deep, flat, booming monotone robotic voice, bit-crushed, utterly without joy |
| The Twelve Squirrels | squeaks and excited chittering only |
| The Dolphins | happy clicks and whistles only |
