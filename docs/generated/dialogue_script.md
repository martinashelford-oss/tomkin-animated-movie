# Dialogue script

All spoken lines from `shots.json`. By default Veo performs them in-clip with lip-sync. To use supplied voices instead, record each shot's lines to `assets/audio/voice_###.wav` (e.g. `voice_001.wav`). The file is mixed over that shot from its first frame, so leave any lead-in silence in the recording.

## Voice sheet

| Role | Voice direction |

| the masked hero | friendly, quick, quippy young man's voice, slightly muffled by the mask |
| the fishing boat | crackly, weather-beaten middle-aged fisherman's voice heard over radio static |
